# TG Server Control

TG Server Control is a private home-monitoring utility operated by its owner.
It displays service health and environmental readings in a private Telegram bot.

The application uses Google Nest Device Access to read the ambient temperature
reported by the owner's Nest Thermostat. It does not provide public access to
the thermostat and does not allow other users to create accounts.
