# Privacy Policy

Last updated: September 4, 2026

TG Server Control is a personal, non-commercial home-monitoring application.
It uses Google Nest Device Access solely to read the ambient temperature from
the application owner's Nest Thermostat and show it to that owner in a private
Telegram bot.

## Data accessed

The application accesses the selected Nest home's device list, thermostat
identity, connectivity information, and ambient temperature required to locate
the thermostat and display its current reading.

## Data storage and sharing

OAuth credentials are stored on the owner's private server. Nest temperature
readings are fetched on demand and are not retained by TG Server Control. The
application does not sell, share, or use Google user data for advertising,
analytics, or profiling.

## Revoking access

The owner can revoke access at any time in Google Account permissions or the
Google Nest Partner Connections Manager. Revocation prevents all further Nest
API access.

## Contact

Questions about this application can be submitted through the project's
