# Настройки хоста

Эти настройки применены к серверу 111.88.242.153 на этапе 5 обслуживания
2026-09-05. Они не применяются установщиком бота автоматически.

## SSH

`ssh-hardening.conf` установлен как
`/etc/ssh/sshd_config.d/00-tg-server-hardening.conf`, root:root 0644.
SSH принимает ключи, прямой вход root запрещён. Пользователь skazimax остаётся
администратором; учётная запись бота tg-server-control не используется для входа.
Ограничений по исходным IP нет по решению владельца сервера.

## Firewall

UFW включён, входящие подключения по умолчанию запрещены, исходящие разрешены.
Разрешены TCP 22 и TCP 443 с любых IPv4 и IPv6 адресов. Правила localhost,
ответного трафика и служебного сетевого обмена обрабатываются стандартными
before-rules UFW. Приложения SOCKS слушают только localhost.

Команды, задающие политику:

```sh
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw default deny routed
sudo ufw allow 22/tcp comment 'SSH from any IP'
sudo ufw allow 443/tcp comment 'MTProto'
```

Перед включением UFW и reload SSH нужно сохранить текущую конфигурацию и правила,
подготовить независимый автоматический откат и оставить административную сессию
открытой. Проверить `sshd -t`, затем отдельный новый SSH-вход с sudo и внешний
TCP 443. Отменять откат только после этих проверок. Облачные security groups
не изменялись и этой конфигурацией не управляются.

Если на хосте появляются другие публичные сервисы, разрешить их порты до запуска.
Эта политика не является универсальным набором правил для любого сервера.
